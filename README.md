# Curso-SQL
Repositório Básico para os Exercícios de SQL



Bootcamp GenAI & Dados - Bradesco & DIO
Trilha: Do Excel ao SQL: Domine seus Dados com Inteligência
Este repositório foi criado para salvaguardar todos os scripts desenvolvidos durante o BootyCamp GenAI & Dados, uma iniciativa do Bradesco em parceria com a DIO. O objetivo central é organizar e documentar o conhecimento técnico adquirido, servindo como uma biblioteca de consulta para exercícios práticos e aplicações reais em engenharia jurídica.

🎯 Objetivo do Projeto
Consolidar a transição do pensamento de planilhas (Excel) para o gerenciamento de bancos de dados relacionais robustos (SQL/PostgreSQL). Os scripts aqui contidos cobrem desde a criação de estruturas de dados até consultas analíticas complexas, fundamentais para a análise de grandes volumes de informações no setor jurídico.

🛠️ Conteúdo do Repositório
O repositório está estruturado para facilitar a localização de comandos essenciais, incluindo:

    DML (Data Manipulation Language): Scripts de inserção e atualização de dados.
    Normalização (1FN): Processos de tratamento de dados para garantir a integridade e eliminar redundâncias.
    Consultas Avançadas: Uso de JOINs, subconsultas e funções agregadas (COUNT, AVG, SUM, MIN, MAX) para geração 
    de relatórios estratégicos.
    Integridade Referencial: Definição de Primary Keys e Foreign Keys para manter o banco de dados coerente e seguro.

🚀 Contexto Profissional
Como Legal Engineer, utilizo estas ferramentas para converter conhecimento jurídico técnico em aprovação e eficiência operacional. Este repositório é parte integrante do meu ecossistema de estudos, que inclui a preparação para o 48º Exame da OAB e minha especialização em Direito Civil e Constitucional.
